The context

What needed to work.

The problem, the part I owned, and the decision that shaped the build.

The brief

Diviniti’s luxury catalogue had more than 500 products. Images loaded slowly, merchandising changes were hard to make, and the team needed clearer insight into how customers used the site.

My role

I worked on Shopify theme development: responsive image choices, custom Liquid sections with merchant-facing settings, and analytics tracking.

The key decision

The image system and the section system solved different parts of the same problem. Responsive assets target load speed, while schema-driven sections let the merchandising team change layouts without editing code.

The result

A 40% reported improvement in Largest Contentful Paint, and a merchandising team that can rearrange page content in the Shopify editor without editing code.

Implementation

How the build came together.

01 / 03

Image architecture

Set responsive sizes, lazy-loading rules, and mobile/desktop image choices so the storefront can send an appropriate asset to each device.

02 / 03

Merchant control

Built more than 20 Liquid sections with schemas for editing and reordering page content in the Shopify editor.

03 / 03

Measurement

Integrated Google Tag Manager and Microsoft Clarity and structured on-page SEO across the catalogue.
